Featured Projects (03)

Top Project · Thesis

SoilSense / AgriSense: Real-Time Soil-to-Crop Predictive Analytics via TinyML

Thesis Team Member · Web & System Development · S.Y. 2026–2027

A low-cost, AI-assisted soil testing system built for Fortunato F. Halili National Agricultural School, where students lack an affordable way to test soil in the field. An ESP32-S3 sensor node in a planter-style enclosure measures nitrogen, phosphorus, potassium, pH, temperature, and humidity, shows a crop recommendation on its LCD, and sends each scan to the AgriSense web app. The app, built with Flask and PostgreSQL, uses a K-Nearest Neighbor model to recommend crops and score soil health, with role-based dashboards for learners and administrators.

  • ESP32-S3
  • TinyML
  • Python Flask
  • PostgreSQL
  • KNN Model
  • HTML / CSS / JS
